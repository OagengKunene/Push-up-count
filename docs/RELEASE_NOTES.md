Download the Windows ZIP, extract the entire folder, and open **PushUpCounter.exe**.
Python and the verified pose model are included. Keep the `_internal` folder beside the executable.

New in version 2:

- Native desktop launcher with camera, profile, variant, goal and tempo controls.
- Guided top/bottom calibration with reusable personal profiles.
- Per-rep lowering, bottom-hold and rising times, target tempo feedback and explained pose scores.
- Offline spoken counts and coaching with a bounded background queue.
- Local interactive workout history, personal records, weekly totals, CSV export and per-rep detail.
- Previous CSV/JSON workouts remain readable; demo sessions are excluded from personal records by default.
- Graceful finish/save control, a bundled model for offline use, and a verified Windows package.

The executable is unsigned. SHA256SUMS.txt identifies the ZIP built by this repository's Windows workflow.
See BUNDLE_VALIDATION.json and the Actions run for software checks. A live webcam check is still needed on the intended PC; camera view, lighting and pose visibility affect results.
